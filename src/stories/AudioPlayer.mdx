# AudioPlayer

The AudioPlayer component provides a comprehensive audio playback interface for podcast episodes. It includes playback controls, progress tracking, playlist management, and persistent state storage via localStorage.

## Features

- **Playback Controls**: Play, pause, seek, and skip functionality
- **Progress Tracking**: Visual progress bar with time display
- **Playlist Support**: Queue management with next/previous navigation
- **State Persistence**: Automatically saves playback position and resumes on reload
- **Responsive Design**: Adapts to different screen sizes
- **Event Handling**: Comprehensive event system for all player interactions

## Usage

```typescript
import { AudioPlayer } from "../controllers/audioPlayer";
import { PodcastStore } from "../store";

// Initialize the store with your state
const store = new PodcastStore(initialState);

// Create the audio player instance
const audioPlayer = new AudioPlayer(store);

// Render the player
audioPlayer.render(store.getState());

// Play an episode
store.playEpisode(episode, playlist);
```

## State Management

The AudioPlayer integrates with the PodcastStore to manage:

- **currentTrack**: The episode currently loaded in the player
- **currentPodcast**: Metadata about the podcast
- **isPlaying**: Boolean indicating playback state
- **trackList**: Array of episodes in the playlist
- **trackMemory**: localStorage persistence for resume functionality

## LocalStorage Schema

```typescript
{
  trackMemory: {
    [trackId: string]: {
      progress: number;      // Percentage (0-100)
      guid: string;          // Episode identifier
      duration: number;      // Total duration in seconds
      currentTime: number;   // Current position in seconds
    }
  }
}
```

## Integration Notes

- The audio player automatically attaches to the `#offbody` container
- Uses native HTML5 `<audio>` element for playback
- Emits state updates through the store's subscription system
- Handles browser visibility changes to pause/resume appropriately
- Responsive design adapts to mobile and desktop layouts
