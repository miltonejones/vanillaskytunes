# PodcastCard

The PodcastCard component displays a podcast with its artwork, title, and subscription status. It includes interactive features like subscription toggling and progress tracking for in-progress episodes.

## Features

- **Podcast Artwork**: Displays podcast cover image
- **Title Display**: Shows podcast name with text truncation for long titles
- **Subscription Toggle**: Star icon to subscribe/unsubscribe
- **Progress Tracking**: Visual progress bar for episodes in progress
- **Interactive Actions**: Click to view podcast details
- **Responsive Layout**: Adapts to grid layouts and different screen sizes
- **State Persistence**: Tracks subscription status and playback progress

## Usage

```typescript
import { renderPodcastCard } from "../views";

// Create state with subscriptions
const state: Partial<IState> = {
  subscriptions: [subscribedPodcast],
  // ... other state properties
};

// Render a single podcast card
const cardHTML = renderPodcastCard(podcast, state);

// Insert into DOM
container.innerHTML = cardHTML;

// Render multiple cards in a grid
const gridHTML = `
  <div class="container-fluid">
    <div class="row">
      ${podcasts.map((p) => renderPodcastCard(p, state)).join("")}
    </div>
  </div>
`;
```

## State Management

The PodcastCard component uses the following state:

- **subscriptions**: Array of subscribed podcasts for displaying subscription status
- **trackMemory**: localStorage data for showing progress bars

## Podcast Data Structure

```typescript
interface IPodcast {
  trackId: number; // Unique identifier
  collectionId: number; // Podcast collection ID
  trackName: string; // Podcast title
  artistName: string; // Podcast author/artist
  feedUrl: string; // RSS feed URL
  artworkUrl100: string; // Artwork image (100x100)
  artworkUrl600?: string; // High-res artwork (600x600)
  collectionName: string; // Collection name
  // ... other metadata
}
```

## Progress Tracking

Progress is stored in localStorage under the `trackMemory` key:

```typescript
{
  trackMemory: {
    [episodeId: string]: {
      guid: string;          // Podcast feed URL
      progress: number;      // Percentage (0-100)
      duration: number;      // Total duration in seconds
      currentTime: number;   // Current position in seconds
    }
  }
}
```

Progress bar displays when:

- Episode progress exists in trackMemory
- Progress is less than 99% (not completed)
- The podcast's feedUrl matches the episode's guid

## Visual Elements

### Card Structure

- **Artwork**: Podcast cover image (typically 100x100px)
- **Title**: Podcast name with ellipsis for overflow
- **Star Icon**: Subscription toggle (outlined/filled)
- **Progress Bar**: Horizontal bar showing playback progress

### Subscription States

- **Not Subscribed**: Outlined star icon, "Subscribe" text
- **Subscribed**: Filled star icon, "Unsubscribe" text

### Progress Bar

- **Color**: Typically blue or accent color
- **Width**: Percentage-based (0-100%)
- **Position**: Bottom of card or below title
- **Visibility**: Only shown when progress exists and < 99%

## Interactive Behavior

### Click Actions

- **Card Click**: Navigate to podcast detail page
- **Star Icon Click**: Toggle subscription status
- **Progress Bar**: Visual only, not interactive

### Hover States

- Card elevation or shadow effect
- Star icon color change
- Cursor pointer indication

## Integration Notes

- Renders as pure HTML string for insertion into DOM
- Uses Bootstrap grid classes for responsive layout
- Integrates with subscription management system
- Reads from localStorage for progress tracking
- Event handlers should be attached after rendering
- Supports both artwork URL sizes (100x100 and 600x600)
