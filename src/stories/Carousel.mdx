# PodcastCarousel

<Subtitle>
  A horizontally scrollable carousel of podcast cards with optional auto-play.
</Subtitle>

<Description>
The **PodcastCarousel** renders a row of podcast cards and lets users navigate
through them using next/previous controls. It can also auto-advance after a
configurable delay.

These stories use a mocked store and a `PodcastCarouselController` under the
hood so you can focus on visual behavior and interaction rather than wiring up
a real data source.

</Description>

## Usage

```ts
// Example args
{
  podcasts: [
    {
      id: "episode-1",
      title: "First Episode",
      description: "Introduction to the show",
      // ...other IPodcast fields
    },
  ],
  autoPlayDelay: 6000, // ms between automatic transitions
}
```
